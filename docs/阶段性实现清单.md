# InkBloom 阶段性实现清单

> 本文档基于项目实际代码梳理，仅汇总已真实实现并可在当前代码库中验证的功能。不包含计划、占位或 stub 待施工项。

---

## 一、项目定位

**InkBloom** 是一款面向自媒体创作者与小说作者的 AIGC 图文创作工具，支持小说长篇创作、自媒体内容生产、以及极简随记三种创作模式，提供「AI 辅助写作 + AIGC 配图 + 知识管理」的一站式创作体验。

---

## 二、创作工作台（前端核心）

### 2.1 三角色创作模式

| 模式 | 定位 | 核心特征 |
|------|------|----------|
| **小说创作** | 长篇连载写作 | 大纲驱动、卷/章层级、记忆与知识图谱、世界观自洽 |
| **自媒体创作** | 平台内容生产 | 选题池、标题工厂、平台风格改写、多平台发布适配 |
| **简约随记** | 灵感碎片记录 | 极简界面、零负担开写、轻量笔记 |

实现要点：
- 角色切换后右侧面板差异化：小说作者显示「批注评审」Tab；自媒体创作者显示「标题工厂」Tab
- 落地页三模式介绍卡片与端差异对比表（桌面端 vs Web 端功能对照）

### 2.2 富文本编辑器（TipTapEditor）

编辑器基于 **TipTap** 框架构建，共用一套内核、三种变体（novel / media / memo），以下是实际已实现的能力：

#### 2.2.1 基础排版能力
- **文字样式**：加粗、斜体、下划线、高亮标记
- **标题层级**：H1 / H2 / H3
- **列表**：无序列表、有序列表
- **引用块**：toggleBlockquote
- **对齐**：左对齐、居中对齐、右对齐
- **代码块**：toggleCodeBlock
- **水平分割线**：setHorizontalRule
- **撤销/重做**：undo / redo

#### 2.2.2 小说专属扩展
- **章节分隔符（ChapterBreak）**：自定义 TipTap 节点扩展，用于标识章节分页
- **角色 @ 提及（CharacterMention）**：输入 `@角色名` 触发提及弹窗，选中后插入带样式的角色引用节点，自动关联当前作品的角色列表

#### 2.2.3 多标签页（TabBar）
- 章节级多开编辑，每个 Tab 独立维护草稿状态
- 点击切换 Tab，关闭前自动 flush 未保存内容
- 中键关闭标签
- 未保存脏标记（黄色圆点），保存中状态（云上传图标）

#### 2.2.4 自动保存
- 每 Tab 独立的 2 秒防抖自动保存（`SAVE_DEBOUNCE_MS = 2000`）
- 切换 Tab / 关闭 Tab / 组件卸载前自动 flush 未落盘内容
- 保存状态实时反馈：未保存 → 保存中 → 已保存 → 保存失败

#### 2.2.5 字数统计
- 实时计算中文字符数 + 英文单词数
- 阅读时长估算（按 500 字/分钟）
- 写作增量追踪：以各 Tab 自身 wordCount 为基线，正增长计入当日仪表盘

#### 2.2.6 标题编辑
- 章节标题可在工具栏下方直接编辑
- 500ms 防抖自动同步至 novel-store 与 tab-store

#### 2.2.7 专注模式
- **全局专注模式**：`Ctrl+Shift+F` 隐藏全部侧栏，编辑区居中（max-w-3xl），沉浸式写作；Esc 退出
- **局部专注**：弹窗编辑器（如大纲要点编辑）支持受控局部专注，由宿主决定布局

#### 2.2.8 图片插入与上传
- **粘贴上传**：`Ctrl+V` 粘贴图片文件 → 自动上传至图床 → 光标处插入图片节点（禁止 base64 内联）
- **拖拽上传**：拖入图片文件到编辑器，自动定位光标落点并上传插入
- **图床选择**：工具栏「图片」按钮唤起 ImagePickerModal，从已上传素材库选择插入
- **AIGC 插入**：生成的图片可通过事件广播定向插入当前激活编辑器

#### 2.2.9 斜杠命令菜单（/ 命令）
- 输入 `/` 唤起 Notion AI 风格的命令菜单，支持键盘 ↑↓ 导航、Enter 执行、Esc 关闭
- **AI 动作**：续写、润色、扩写、缩写、续写对话（执行后触发 N 选 1 候选面板）
- **格式块**：H1 / H2 / H3、无序列表、有序列表、引用、代码块、分割线
- **图片**：唤起图床选择弹窗

#### 2.2.10 内联续写（Inline Completion）
- 快捷键 `Ctrl+Space` 触发（仅小说模式）
- 取光标前后各 500 字符作为上下文，调用 AI 生成续写建议
- 浮层显示建议内容，`Tab` 接受插入，`Esc` 取消
- 流式生成中显示「生成中…」动画

#### 2.2.11 右键改写菜单（ContextMenu）
- 选中文本后右键弹出菜单：润色、扩写、缩写、去 AI 化
- 触发后进入 N 选 1 候选面板（CandidatesPanel），展示多个 AI 生成版本供选择

#### 2.2.12 DiffViewer（改写对比）
- AI 改写后弹出左右对比视图：原文 vs 修改后
- 支持「接受改写」（替换编辑器原文）/「拒绝改写」（放弃）

#### 2.2.13 内容插入广播
- 外部模块（如 AIGC 预览、引导字段）通过 `inkbloom:insert-content` 事件投递 HTML 到编辑器
- 多实例并存时按「最近一次聚焦」或 `data-inkbloom-editor` 定向插入
- plain 预设（记忆弹窗编辑器）不接收外部插入，避免误落

#### 2.2.14 文本定位
- 批注评审面板点击「定位到原文」，通过 `inkbloom:locate-text` 事件在编辑器中高亮并滚动到对应文本
- 支持完整匹配退化到前 12 字匹配

### 2.3 全局交互与导航

- **命令面板（Command Palette）**：`Ctrl+K` 唤起，支持作品/章节搜索与命令快速跳转，↑↓ 导航、Enter 执行、Esc 关闭
- **全局快捷键**：
  - `Ctrl+B` 展开/折叠左侧目录面板
  - `Ctrl+J` 展开/折叠右侧 AI 面板
  - `Ctrl+I` 展开/折叠整体分析面板
  - `Ctrl+K` 命令面板
  - `Ctrl+/` 快捷键帮助
  - `Ctrl+Shift+F` 专注模式
- **拖拽调整面板宽度**：左/右/分析三面板支持拖拽调整（raf 节流），低于最小宽度自动折叠
- **快捷键帮助弹窗**：全局快捷键速查

## 三、AI 能力体系

### 3.1 AI 对话助手（AIChatPanel）

- **流式对话**：SSE 流式响应，实时显示 AI 回复内容
- **模型选择**：下拉选择不同 LLM 模型
- **语音输入**：浏览器 Web Speech API 语音转写，增量追加到输入框，收音中显示脉冲动画
- **灵感建议**：空状态展示 4 条预设建议词（如"帮我为反派设计一个反转动机"）
- **一键清空**：Trash2 图标清空当前会话历史
- **打字机指示器**：AI 思考中显示三弹跳球动画

### 3.2 AI 续写与改写（已通过斜杠命令、右键菜单、内联补全实现）

- **续写（continue）**：基于上文生成多个候选走向
- **润色（polish）**：优化当前段落文字质感
- **扩写（expand）**：扩展细节、氛围与心理描写
- **缩写（condense）**：凝练表达，压缩冗余
- **续写对话（dialogue）**：生成角色对白候选
- **内联补全（inline）**：`Ctrl+Space` 行内智能续写
- **改写对比（rewrite + diff）**：右键改写后弹 DiffViewer 对比原文与修改稿

### 3.3 自媒体标题工厂（TitleFactoryPanel）

- 基于内容自动生成多个标题候选
- 支持不同平台风格的标题改写

## 四、AIGC 图片生成

### 4.1 文生图

- **双供应商**：Pollinations（默认）+ DALL·E
- **自定义尺寸**：支持 1024×1024 等规格
- **Prompt 智能生成**：根据上下文自动生成英文图片 prompt（调用 `/api/prompt/image`）

### 4.2 素材管理（GalleryGrid / 图床）

- **统一图库**：所有生成图片自动入库（assets 表）
- **素材去重**：相同图片自动去重
- **缩略图**：自动生成缩略图
- **图库管理**：列表/网格浏览、删除
- **插入编辑器**：一键将图片插入当前编辑位置

## 五、知识管理体系

### 5.1 知识图谱（KnowledgePanel）

- **实体提取**：从当前章节内容自动提取人物、地点、组织等实体（调用 AI Service `/api/knowledge/extract`）
- **关系提取**：识别实体间的关系
- **一致性检测**：检测新写内容与已有设定是否冲突，标注不一致处（error / warning / info 三级严重度）
- **知识可视化**：KnowledgeGraph 组件展示节点与关系图
- **节点详情卡片**：点击节点显示名称、类型、描述

### 5.2 记忆系统（MemoryPanel）

- **四分组管理**：人物卡、设定集、前情摘要、灵感素材
- **作品级隔离**：按 novel_id 隔离，自媒体模式为全局单份
- **富文本编辑器**：每条记忆内容使用 TipTapEditor（plain 预设）编辑
- **搜索与标签**：支持名称/内容/标签搜索；快捷标签筛选（localStorage 持久化）
- **置顶**：Pin 置顶，AI 优先参考
- **拖拽排序**：组内拖拽调整顺序
- **多窗口编辑**：支持同时打开多个记忆条目编辑窗口，可最小化挂起
- **展开大视图**：Maximize2 按钮唤起全屏记忆管理视图

### 5.3 大纲管理（OutlinePanel）

- **幕结构（Act-based）**：支持多幕组织，每幕含多个章节要点
- **节点状态追踪**：planned / drafting / done 三态，带颜色标识
- **大纲进度可视化**：顶部进度条显示完成百分比
- **大纲与章节关联**：节点可绑定具体 chapter_id，显示「成稿」跳转标签
- **AI 扩写成稿**：点击「扩写」调用 AI 生成初稿，结合记忆上下文（人物/设定/前情/灵感，按可见性规则过滤），预览后一键创建章节
- **展开大视图**：OutlineExpandedView 全屏大纲管理
- **要点编辑弹窗**：富文本编辑器编辑章节要点摘要，支持局部专注模式

## 九、用户与账户体系

### 9.1 认证与授权

- **手机号注册/登录**：短信验证码方式
- **JWT 会话管理**：Access Token + Refresh Token 双令牌
- **游客模式**：Web 端未登录展示落地页（LandingPage）→ 登录/注册
- **桌面端免登录**：本地模式 AuthJWT 中间件无 token 时注入 uid=0 放行，断网可用
- **登录态持久化**：localStorage 自动恢复会话，启动时 `/auth/me` 校验

### 9.2 订阅与计费

- **订阅状态机**：trial / active / expired 三态
- **过期只读限制**：订阅过期后作品变为只读（`subService.ReadOnly` 中间件拦截写入）
- **Token 账户体系**：
  - Token 余额查询与充值
  - Token 消耗流水（prompt_tokens / completion_tokens）
  - AI 调用按 Token 计费（流式 SSE 尾帧 usage 回收）
- **支付渠道**：仅沙箱支付（SandboxProvider）可用，即时到账模拟
- **订阅弹窗**：402 拦截时自动唤起
- **Token 钱包弹窗**：余额不足时自动唤起

### 9.3 用户管理

- **演示账号**：内置 id=1 演示账号（13800000000 / inkbloom123）
- **用户协议与隐私政策**：注册时强制勾选（`agreed_terms_at` 字段记录）；协议页独立路由 `/legal/:slug`
- **账号注销**：15 天冷静期机制（`users.status = 2`）

> ⚠️ 真实支付（支付宝/微信）与真实短信通道当前为占位 stub，未实际接入。

## 十、数据同步与备份

### 10.1 .inkbloom 数据包

- **导出**：将作品/章节/大纲/记忆/素材打包为 `.inkbloom` 文件
- **导入**：解析 `.inkbloom` 包，支持 created / updated / conflict 三种结果计数
- **跨端迁移**：桌面端本地数据可导出为包，Web 端可导入；反向亦可

### 10.2 桌面端备份（Electron 专属）

- **自动备份**：启动时快照（≥24h 间隔）+ 每日 03:00 定时备份
- **DB 快照**：SQLite `VACUUM INTO` 快照（`.db` 文件）
- **素材备份**：assets 目录增量归档（`.assets.zip`）
- **备份恢复**：桌面端菜单「从备份恢复」→ 列出备份 → 选择 → 恢复 DB + 解压素材 → 重启内嵌服务
- **保留策略**：自动清理旧备份

## 十一、桌面端（Electron）

### 11.1 架构

- **Electron + 嵌入式 Go Server**：主进程启动内嵌 Go 服务（local mode: SQLite + 内存 kv + LocalBus）
- **离线可用**：监听 `127.0.0.1:18080`，无需联网即可创作
- **云端增强**：AI 能力与云同步需联网登录云端账号

### 11.2 产品化功能

- **应用菜单**：文件/设置/帮助标准菜单
- **数据目录访问**：一键打开本地数据目录
- **云同步入口**：「数据与云同步」菜单项（唤起渲染进程 DataModal）
- **单实例锁**：防止重复启动
- **优雅关机**：关闭时等待服务安全停止
- **崩溃恢复**：内嵌服务异常退出后弹窗提示，可选择重新启动服务/打开日志/退出

> ⚠️ 桌面端自动更新当前为骨架实现，更新 feed URL 为占位地址，尚未配置真实更新通道。

## 十二、运营与安全

### 12.1 运营后台（AdminPanel）

- **管理员面板**：按 role 条件渲染入口
- **用户管理**：查询、封禁/解封
- **订阅管理**：查询、手动延期
- **Token 管理**：查询、手动充值
- **反馈管理**：用户反馈查看与处理

### 12.2 功能开关

- **灰度发布**：服务端配置功能开关（如 `desktop_download`）
- **前端动态拉取**：启动时拉取公开 flags

### 12.3 内容安全

- **阿里云内容安全网关**：文本审核 + 图片审核（`pkg/contentsafety/aliyun.go`）
- **接入点**：
  - AI 文本：prompt 输入校验 + SSE 输出聚合后校验
  - 文生图：prompt 送检 + 生成图落库前图片送检
- **违规记录**：`content_violations` 表记录违规详情，供运营复审
- **自动退款**：违规图片任务失败自动退回 Token
- **配置开关**：`contentsafety.enabled` + provider 配置；未启用时打 WARN 日志

### 12.4 安全基线

- **全站限流**：Redis 滑动窗口 / 内存限流（local 模式降级）
  - 未登录 IP 限流：5 req/s + 500 次/日
  - 登录用户限流：20 req/s + 20,000 次/日
  - AI 接口限流：1 req/s + 300 次/日
  - 短信限流：60s 间隔 + 日 5 条
- **CORS 白名单**：配置驱动，生产域名精确控制
- **WS 鉴权**：Query Token + Origin 白名单校验
- **JWT Secret**：本地模式随机生成，云端拒绝默认密钥启动
