## 设计

左侧「架构」栏从"编辑器"降级为"导航器"，真正的编辑体验升入中央标签页——
与记忆条目（memory tab）同构。

- `tab-store.ts`：TabKind 增加 `'architecture'`；全局单例 `ARCH_TAB_KEY`（meta.novelId 定位作品）。
- 新建 `components/architecture/ArchitectureEditor.tsx`：左右分栏——左侧组类/条目导航
  （内联添加），右侧选中条目标题+内容宽幅编辑区；无选中时编辑基本信息表单。
- `EditorArea.tsx`：panel 类 tab 渲染分支 + `inkbloom:open-architecture` 事件监听
  （openPanelTab 复用单例并刷新 meta.novelId）。
- `ArchitecturePanel.tsx` 原地重构为轻量导航：基本信息只读摘要 + 组类计数/条目跳转 +
  内联快速添加；点击条目经 architecture-store.focus 定位中央编辑器。
- 数据层零迁移：仍走 architecture-store（localStorage），AIGC 注入链路
  （architectureText）零影响。
- 决策点 Q1（条目内容升级轻 TipTap）：用户未拍板 → 按纯 textarea 先做。
