# F1 · 内测门禁：安全与部署修复

## 目标

清零审计报告中「工程缺陷」的 P0 与高价值 P1，使新克隆仓库可一键启动、无后门、无越权、计费不可绕过。

## 已核实的关键事实（决定方案走向）

| 事实 | 影响 |
|---|---|
| `users.id=1`（`13800000000`）是 `migrations/010_user_isolation.up.sql` 的**历史数据回填归属目标**：全表 `user_id DEFAULT 1` | **不能直接删除** EnsureDemoUser，否则历史数据无人拥有。改为「保留账号、剥夺登录能力」 |
| `assetRequestAllowed`（`http.go:699-713`）**Bearer 分支只验 token 有效，完全不校验 filepath 归属** | 比签名分支更严重：任意登录用户带 Bearer 即可读全站任何文件。签名分支也只是验 HMAC，不验归属 |
| 资产路径含 novelID：`/assets/files/{novelID}/assets`（`sync_import2.go:370`），另有共享前缀 `/assets/files/_media`（`:354-355`） | 归属校验可按路径解析 novelID；`_media` 走白名单放行 |
| `signedurl` 签名绑定 `(uid, path, exp)`，HMAC 用 JWT secret（`signedurl.go:32-36`） | 签名只证明「签给了谁」，不证明「谁拥有」，两层都要补归属校验 |
| `ensureJWTSecret` 仅在 local 模式生成随机密钥（`main.go:548-561`），cloud 保持原样后由 `config.go:258` 拒绝空值 | compose 必须显式注入 `INKBLOOM_JWT_SECRET` |
| `docker-compose.yml:58-64` env 块无 `INKBLOOM_JWT_SECRET`，且 `INKBLOOM_SERVER_MODE=release`（cloud）→ 启动被拒 | 默认部署路径 100% 失败 |

## 决策

1. **演示账号保留但不可登录**：继续 seed（保数据归属），密码改 `crypto/rand` 随机生成且不落日志；cloud 模式额外置 `status=disabled`。管理员白名单从 `config.yaml` 清空。
2. **资产归属校验下沉到单一函数**：新增 `internal/pkg/assetguard`，`assetRequestAllowed` 的两条分支（sig / Bearer）统一先解析出 uid，再校验 uid 对该 filepath 的所有权；`/assets/sign` 复用同一校验，不拥有则 404。
3. **计费与退款不复用请求 ctx**：统一 `context.WithoutCancel` + 独立 5s 超时；失败落库 + Warn 升级为 Error 并计数。
4. **不引入新依赖**：短信/支付走 F4，本 spec 不涉及。

## F1-4 资产越权（P0）

**新增** `internal/pkg/assetguard/guard.go`
```go
type Guardian interface {
    // Owns reports whether userID owns the asset at a /assets/files/... path.
    Owns(ctx context.Context, userID int64, assetPath string) (bool, error)
}
```
实现：解析 `strings.TrimPrefix(path, "/assets/files/")` 首段；首段 == `_media` → 放行（共享素材）；否则 `strconv.ParseInt` 得 novelID → 依赖注入的 `NovelLookup.GetByID(ctx, userID, novelID) != nil` → 归属成立。解析失败一律拒绝（fail-closed）。

**改** `internal/server/http.go:699` `assetRequestAllowed` —— 签名分支与 Bearer 分支统一：先取 uid（sig 的 uid 或 Bearer 解析出的 uid），再 `guard.Owns(ctx, uid, "/assets/files"+filepath)`，非 200 拥有者一律 false。

**改** `http.go:367-374` `/assets/sign` —— 签发前调用 `Owns`，否则 404（不泄露存在性）。

**改** `internal/handler/aigc_handler.go:587` `GetAsset` —— `GetByID` → `GetByUserAndID(ctx, GetUserID(c), id)`。

**改** `internal/handler/portrait_handler.go:65` `UploadNovelPortrait` —— 先 `novelRepo.GetByID(ctx, GetUserID(c), novelID)`，nil 则 404。

**装配** `cmd/server/main.go` —— guardian 注入 `HTTPServer`（新增字段 `AssetGuard`）。
