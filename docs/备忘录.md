# 个人备忘录
> 本项目的 idea

不仅是编辑器，还是小说阅读器：交互式微创作的小说阅读体验，低消耗的小说微调玩法

发现页的内容社区也是产品的一个商业潜力点

自媒体创作模式如何实现常见平台的web自动化起稿呢？

本作品如何去中心化，尽可能减少创作者和读者之间利益互换的损耗，从而吸引创作者自己开拓读者用户，这意味着本作品主要从AI业务和用户的注意力资源上面赚钱，而不是抽成模式

灵感、阅读、获赞代表着人类的智慧价值、注意力价值、认同价值，本作品的盈利建立在这三种价值之上。

要在阅文作家助手之上去思考，才能取得优势

人类可以创作一条故事主线、世界骨架，宣扬特定的主题，但可以呈现多分支，做到千人千面。创作者贡献了智慧价值，读者贡献了注意力和认同，而AI把更多读者纳入同一智慧来源的衍生领域里面去了。AI只是创作者的放大器，并没有自行产生价值的根据，所以如何让创作者选择在这个平台使用AI，就是核心问题。

图床居然是公开共享的，没有鉴权，没有区分用户吗？

既然文本被AI解决了，那么小说创作不应该升维到图创作，或者流创作吗？
